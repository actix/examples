# TLS Client Certificates Using Rustls

## Usage

### Certificate

The `certs` directory contains the server and client certificates, their private keys, and the CA certificate generated by [`mkcert`] that signed them.

### Server

```sh
cd https-tls/rustls-client-cert
cargo run
```

The server runs HTTP on port 8080 and HTTPS on port 8443.

### Client Certificates

Run the client commands from `https-tls/rustls-client-cert` in another terminal.

Using [HTTPie]:

```sh
http https://127.0.0.1:8443/ --verify=certs/rootCA.pem --cert=certs/client-cert.pem --cert-key=certs/client-key.pem
```

Using [curl]:

```sh
curl https://127.0.0.1:8443/ --cacert certs/rootCA.pem --cert certs/client-cert.pem --key certs/client-key.pem
```

[`mkcert`]: https://github.com/FiloSottile/mkcert
[curl]: https://curl.se/
[HTTPie]: https://httpie.io/cli
