# HTTPS Server Using OpenSSL

## Usage

```sh
cd https-tls/openssl
```

### Certificate

The included certificate is for demonstration. To create a certificate trusted by your browser, install [`mkcert`], install its local CA, and generate a new certificate and private key in this directory:

```sh
mkcert -install
mkcert -key-file key.pem -cert-file cert.pem 127.0.0.1 localhost
```

This writes `key.pem` and `cert.pem`. In `src/main.rs`, replace the `load_encrypted_private_key` call with the commented `set_private_key_file` block to load the unencrypted key generated by mkcert.

### Server

```sh
cargo run
```

### Client

- curl: `curl -vk https://127.0.0.1:8443`
- curl (forced HTTP/1.1): `curl -vk --http1.1 https://127.0.0.1:8443`
- Browser: <https://127.0.0.1:8443>

## Encrypted Private Key

To use the encrypted-key loader instead, generate `key.pem` and `cert.pem` with the command below. Enter `password` as the key passphrase to match the loader in `src/main.rs`.

```sh
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -sha256 -days 365
```
